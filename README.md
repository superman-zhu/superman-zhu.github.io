# superman-zhu.github.io

Personal site for Jiaqi Zhu — undergraduate at NYU Shanghai, Business and Finance & Data Science, Class of 2027. Collects course reports, case studies, and project code from my undergraduate years.

**Live at [superman-zhu.github.io](https://superman-zhu.github.io)**

## Build

There isn't one. The whole site is a single `index.html` — markup, styles, and scripts in one file, no framework, no dependencies, no build step. Open it in a browser to preview; push to `main` to deploy via GitHub Pages.

Everything else in the repo is content: PDFs, notebooks, and screenshots the page links to.

## Features

- Light and dark themes, following the OS by default with a manual toggle that persists
- Responsive down to mobile
- Click-to-enlarge image viewer with keyboard navigation
- Scroll-reveal animations, disabled under `prefers-reduced-motion`
